# Westafary

Site vitrine de la maison Westafary : joncs sculptés et manchettes en acier inoxydable doré.

Le site est statique (HTML, CSS, JS) et relié à la boutique Shopify : les fiches produits, le panier et le paiement restent sur westafary.myshopify.com.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000

## Publier sur GitHub Pages

Settings › Pages › Source : branche `main`, dossier `/ (root)`.

## Fichiers

- `index.html` : la page
- `style.css` : le design
- `main.js` : produits, teintes Soraya, menu mobile, animations
